当前公开材料只修正不可移植的Markdown链接：项目内文件改用相对路径，项目外旧课程参考指向本说明，不公开的BSON实体链接改指对应恢复清单。过去ZIP提交副本的转换已记录在当时的审计文件中；此次Git提交的修改范围以分支提交记录为准。docs/evidence下的既有历史JSON与原始截图内容保持字节一致。
