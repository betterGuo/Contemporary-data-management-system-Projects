## 定义模型与默认值

single、multiple、text、number对应原文单选、多选、文本填空和数字填空。题目id、选项id、规则id稳定，不用显示序号解释答案。validation与jumpRules存在MongoDB，修改配置即可改变行为，禁止把具体问卷选项或阈值写死在代码。

| 类型 | 可配置项 | 未设置时 |
| --- | --- | --- |
| single | options、required | 非必答，可留空 |
| multiple | options、required、minSelections/maxSelections | min=0，max=选项数；恰好n表示min=max=n |
| text | required、minLength/maxLength | min=0；max仅受公开资源边界约束 |
| number | required、minValue/maxValue、integerOnly | 上下界分别不限制；integerOnly=false |

限制可独立设置。实际到达的多选有效下限=max(minSelections,required?1:0)，文本有效下限=max(minLength,required?1:0)。required=false不能覆盖正下限；下限2的空数组或空文本非法。非必答数字可留空，数值下限不等同于字数/数量下限。

文本去两端空白、NFC规范化后按Unicode码点计数；数字用字符串输入，精确解析普通十进制或科学计数为Decimal，再精确存Decimal128；拒绝bool、NaN、Infinity、溢出及不精确舍入。前端使用BigInt系数和十进制指数比较，不经Number或parseFloat。0为有效答案，18与18.0、-0与0规范化相同。手机号整数示例不擅自增加11位或号段要求，同时说明整数不能保留前导零。

## 跳转条件

| 来源 | 运算符 | 匹配含义 |
| --- | --- | --- |
| single | eq | optionId相等 |
| multiple | containsAny | 与非空条件集合有交集 |
| multiple | containsAll | 包含条件集合全部选项 |
| multiple | equalsSet | 集合相同，顺序无关 |
| number | eq/lt/lte/gt/gte | 精确十进制比较 |
| number | between | 两端包含 |

每题按规则数组顺序找第一条命中，未命中进入下一题，末题默认END。合法空答不触发普通答案条件，默认下一题。第一阶段只跳后续题或END，这是公开约定；原文未规定回跳语义，后续如需回跳须补重访和终止模型。

配置校验检查来源题型、运算符、条件值、选项引用、目标属于本卷、向前方向和规则id唯一；between下界不得大于上界；重排或删除后重新检查全部引用，不保存悬空配置。发布前验证完整定义，空问卷不可发布。

## 服务端路径重放

```text
从首题开始，visited为空
每一步先检查该题未被重复访问且未超过执行上限
规范化答案并校验required和数量/字数/数值条件
记录到达题
合法空答：默认下一题
非空答案：取首条匹配跳转，否则默认下一题
直到END
拒绝未知题、重复questionId及visited之外的客户端答案
仅保存路径上有效非空答案及服务端计算的visited
```

被跳过题即使必答也不校验。前端返回修改前题时重算分支并清理旧分支答案；后端提交重放，不接受客户端声明的路径。到达的新分支若有必答，必须补答。异常历史循环明确失败，不无限运行。

## 版本、摘要和重试顺序

POST必须携带GET定义返回的definitionVersion；服务端按该版本读取规范化，摘要包括版本、匿名选择、标准答案，排除Cookie、CSRF和submissionKey。历史定义的路径与答案形状先校验，再确认已成功请求，最后检查新请求准入。此顺序同时拒绝“在原成功payload夹带路径外空答”的重试，并使同键同内容在关闭或版本停止新提交后仍返回原回执；同键不同合法答案或匿名选择冲突；新键受当前版本、状态、截止和重复开关限制。

## 数字平均的实际精度策略

输入答案必须能精确存入Decimal128，但统计相加的中间值可能超出该表示域。联调发现直接$avg在最大有限值及正负大数抵消场景不可靠；最终API改由exact_numeric_average流式读取有效答案，在12400+数字回答数量位数的Decimal精度下求和，最后除法保留34位有效数字。0、负数、细小小数都参与；无数字返回null。补充回归是两份最大有限值平均仍等于原值，以及[1e40,1,-1e40]平均为34位有效数字的1/3。最大有限值及抵消固定回归在本次test-results.json记录通过，原始输出与逻辑说明分开保存。

## 复核补充边界

题ID由服务端默认生成，也可提交稳定自定义ID；自定义ID保留普通Unicode、斜线、百分号，但拒绝END、.、..及Cc/Cs字符。引用必须仍是本卷已有合法题ID，规则中的条件和目标不会被当作脚本执行。特殊ID通过真实HTTP线路验证编辑、删除、重加、发布、填写和单题统计，不为适配TestClient额外解码现象而添加业务二次解码。
