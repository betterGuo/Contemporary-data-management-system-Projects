## 固定样本与手算基准

样本名称采用第二阶段手测前缀。A为基础流程，B为复用问卷，C为版本问卷，D为共享问卷，E为双实例问卷；不要与初次演示seed中的“问卷甲/乙”混用。

| 样本 | 实际定义与输入 | 已确认结果 |
| --- | --- | --- |
| A 基础流程 | 四题型；年龄0～120整数。两份正式答卷分别完整路径年龄0、跳转路径年龄20 | 2答卷、同一填写账号；年龄均值10，中间被跳过题不按0计入 |
| B 复用问卷 | 年龄原v1回答40；学习时长原v1上限24回答4 | 与A合并年龄原v1：3回答、3答卷、2问卷、均值20；学时v1只计B的4 |
| C 版本问卷 | 同一实例由学习时长v1显式升级v2，上限12；正式回答8 | 20被校验拦截，8通过；学时v2均值8，不纳入v1 |
| D 共享问卷 | 接收者选用原学时v1，上限24；已有唯一正式答案6 | 作者原v1均值仍4、接收者本人原v1均值6；撤回后D快照和答案保持 |
| E 双实例问卷 | 从D快照派生的私有副本v1选入同卷两次，一份正式答卷分别填6和10 | 2回答、1答卷、1问卷、均值8、最小6/最大10、本卷去重账号1；不同实例ID |
| 副本后续v2 | 两个编辑页先载入同一旧修订；A改上限16先保存，B改8后提交 | 只生成副本v2，上限16；B提示冲突并保留8及说明，无v3；E仍两个v1上限24 |

A至D主要由用户完成前段操作；D正式答案6在AI接手时已经存在，未重复提交，也不补写其此前点击提交的观察过程。E、后段副本和双页冲突由AI执行。撤回授权经用户明确同意后通过现有业务服务调用；标签保存和重命名也采用服务调用，筛选及移除收藏为真实页面操作。原生确认框或prompt的受阻交互没有被记为本轮完整UI通过。

## 结果判定与保留的边界

原文八项需求均有核心运行证据。公共管理员维护、归档或停止新选用、异常输入、失败回滚等组合已有自动或隔离浏览器结果，本轮固定样本没有再次把所有组合人工重做。[验收矩阵](acceptance.md)中8行“部分验证”明确的是更细的组合边界，不代表必交材料缺失，也不改写为全部变体通过。

失败及修复历史继续保留：初次223通过1失败为备份测试夹具误用严格集合；243通过1失败为错误码断言过窄；临时库名超长与浏览器异步等待也分别记录。后续复查发现的真实业务缺陷及修复前证据见[复查记录](recheck-2026-10-26.md)。正式版本正文、旧问卷及答卷指纹是保护依据，成功页面和用例数量不能代替数据一致性核对。
