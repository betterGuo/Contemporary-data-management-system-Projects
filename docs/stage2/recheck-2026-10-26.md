## 本轮发现并修复的问题

| 问题 | 修复及验证 |
| --- | --- |
| 本地题标题、选项/规则ID及文本回答中的孤立Unicode代理字符可能在编码时500 | 共享请求模型递归检查字符串与对象键，提前返回结构化422；普通合法Unicode仍由原回归保护 |
| 超大revision、definitionVersion或分页参数可能导致BSON溢出500；部分旧接口误判为409 | 请求整数限定BSON int64范围，分页按最大100条计算安全上界，服务层也校验；六类分页入口及版本/修订号边界均补测 |
| 非维护者能够绕过停用版详情限制，从跨卷统计读取旧版标题和选项 | 没有本人快照时，同步要求版本仍可读可选；维护者和合法持有人仍可统计，私有共享题/公共题均实测 |
| 归档/停用后的已有收藏无法只改标签；省略versionId又能新增归档收藏 | 区分原收藏版本的标签整理与新增/换版本；前端保留原收藏版本，包括自动收藏的null；新增归档收藏拒绝 |
| 无可查看版本时，收藏标签已提交却在响应投影阶段返回404 | 响应投影与收藏写入放入同一事务并传session；404会回滚写入。独立个人标签重命名仍可使用，不借整理标签读取失效来源 |
| 保存期间继续输入，成功回读会覆盖后输入文字；快速连续保存也可能使用旧revision | 从写入开始到回读完成让编辑与选题区域inert，防重复保存；三条保存路径及409失败输入保留均通过真实鼠标键盘验证 |
