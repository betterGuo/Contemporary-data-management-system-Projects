## 实际操作范围

以下行为通过页面真实点击、填写和弹窗完成：

- 原demo_owner账号登录，查看从第一阶段数据迁移的题目。
- UI注册独立QA用户，创建数字题编辑稿、设置整数及0～120校验、显式生成v1。
- 输入个人收藏标签。
- 创建两份问卷，各自从题库选用v1并发布；检查引用内容在问卷编辑器内只读。
- 发布后普通保存编辑稿按钮禁用。
- 两份问卷分别实际填写20、40并提交。
- 编辑来源生成v2；只读API断言旧问卷仍引用v1、标题未改。
- 查看跨卷v1汇总；只读API断言回答2次、答卷2份、来源问卷2份、均值30，响应没有原始值明细。
- 共享给另一QA用户，该用户从共享题库选用到自己的问卷。
- 原作者撤回共享；接收者仍能查看自己问卷快照，源版本访问被拒绝。
- 接收者通过快照按钮创建独立个人副本，来源根保留。
- 从v1恢复成v3，再将v3停止新选用，历史内容保留。
- 在360px视口查看题库和原编辑器，断言文档无横向溢出。

API只用于读取并核对UI操作后的结果，没有用API写入来冒充上述UI验收。准备用户本身也通过注册页面完成。

## 历史尝试与网络拒绝

保留最初根目录记录以及attempt-2、attempt-3的真实失败。前三轮失败属于QA脚本的等待时机：提示框之后过早读取标签、创建问卷后已导航导致读取响应体失败、版本下架后立即计数未等待DOM更新。后续分别改为等待真实写请求响应、从导航后的页面读取问卷、等待下架状态按钮。没有把这些脚本失败写成系统业务缺陷。

最终出现4条预期网络拒绝日志：未登录进入登录/注册页时的会话探测401，以及撤回共享后访问来源的404；它们与JavaScript执行异常分别记录。最终`pageErrors=[]`、`unexpectedConsoleErrors=[]`。

## 复现

脚本为 `scripts/browser_stage2.cjs`，依赖Playwright及Chromium/Chrome。启动隔离预览服务后指定新的输出目录，保留历史证据：

```sh
STAGE2_BROWSER_OUTPUT=docs/evidence/stage2/browser-new-run \
NODE_PATH=/path/to/node_modules \
BROWSER_EXECUTABLE_PATH=/path/to/chrome \
node scripts/browser_stage2.cjs
```

本脚本仅验收有意准备的预览环境，不作为最终正式库的数据生成脚本。
